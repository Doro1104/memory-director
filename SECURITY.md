# Security and privacy reports

Do not post private media, credentials, databases, raw logs, local paths or certificate keys in public issues. Provide a minimal reproduction with synthetic images and the sanitized doctor.py summary. If a future repository enables private vulnerability reporting, use that mechanism for security-sensitive details.

Deployment defaults to loopback. LAN access is opt-in, uses TLS and requires account authentication. This preview is for a trusted home network; do not expose it directly to the Internet. The deployment skill is a workflow policy, not a process sandbox or a guarantee against other software with equal operating-system permissions.
